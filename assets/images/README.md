# Tomato Image Assets

Place the following tomato images in this folder:

1. **tomato_unripe.png** - Green unripe tomato (shown at 0-50% progress)
2. **tomato_half_ripe.png** - Half-ripe orange-green tomato (shown at 50-100% progress)
3. **tomato_ripe.png** - Fully ripe red tomato (shown when collectible)

## Image Requirements

- **Format:** PNG with transparency
- **Recommended Size:** 512x512 pixels or larger
- **Aspect Ratio:** Square (1:1)
- **Background:** Transparent

## Current Image Files to Add

The user has provided 3 tomato images that should be saved as:
- Green tomato → `tomato_unripe.png`
- Green-red gradient tomato → `tomato_half_ripe.png`  
- Red tomato → `tomato_ripe.png`

## Fallback Behavior

If images are not found, the app will fall back to the programmatically drawn tomato character.
