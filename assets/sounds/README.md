# Sound Assets

This folder is for ambient sound files.

## Currently Using Online Sources

The app currently streams sounds from royalty-free online sources (Mixkit).
For offline support, download and place MP3 files here:

- `rain.mp3` - Rain ambience
- `forest.mp3` - Forest with birds
- `ocean.mp3` - Ocean waves
- `cafe.mp3` - Coffee shop ambience
- `fireplace.mp3` - Crackling fireplace

## Recommended Sources for Royalty-Free Sounds

- [Mixkit](https://mixkit.co/free-sound-effects/)
- [Freesound](https://freesound.org/)
- [Pixabay](https://pixabay.com/sound-effects/)

## Requirements

- **Format:** MP3 or WAV
- **Duration:** 30 seconds to 5 minutes (will loop)
- **Quality:** 128kbps or higher
